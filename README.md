# QuizFlow AI

Русскоязычная платформа для одного преподавателя: импорт тестов DOCX/PDF, генерация вопросов из учебных материалов с OpenAI, редактор, публикация ссылок, прохождение без регистрации, детерминированная серверная проверка, статистика и CSV.

## Локальный запуск

1. Node.js 20+; `npm install`.
2. Создайте проект на https://supabase.com и выполните SQL из `supabase/migrations/001_initial.sql` в **SQL Editor**.
3. В Supabase → Authentication → Users создайте преподавателя (email/password). В `TEACHER_EMAIL` внесите **именно этот email**. В Supabase Auth настройте Site URL и допустимые Redirect URLs для локального и production-домена.
4. `cp .env.example .env.local` и заполните URL, public anon key, private service role key, email преподавателя и `OPENAI_API_KEY` (https://platform.openai.com/api-keys). Не добавляйте `.env.local` в git. Public variables are intended to be exposed; service role and OpenAI key must remain private.
5. `npm run dev` → http://localhost:3000/login. `npm test`, `npm run lint`, `npm run build`.

## GitHub / Vercel

Создайте пустой приватный репозиторий GitHub. Из папки проекта: `git init`, `git add .`, `git commit -m "Initial QuizFlow AI"`, `git branch -M main`, `git remote add origin <YOUR_REPO_URL>`, `git push -u origin main`. Импортируйте репозиторий на https://vercel.com. В настройках Environment Variables задайте все ключи из `.env.example` (кроме необязательных Redis-переменных), `NEXT_PUBLIC_SITE_URL=https://YOUR_DOMAIN`. Разверните приложение и добавьте адрес в Supabase Authentication → URL Configuration. Обновите deployment после изменения env.

## Архитектура / безопасность

- Next.js App Router / TypeScript / Tailwind / Supabase Auth / PostgreSQL / OpenAI (Structured Outputs) / Mammoth / pdf-parse / Zod.
- Все запросы к приватной БД выполняются только сервером с service role после проверки Supabase Auth и `TEACHER_EMAIL`. Для учащихся сервер отдаёт только разрешённые публичные поля, без `correctOptionId`.
- Каждое редактирование теста создаёт новую неизменяемую версию. Попытка связана с конкретной версией. Обработка ответов и подсчёт баллов происходят в одной транзакции в PostgreSQL (`submit_quiz`); повторная отправка с тем же UUID идемпотентна.
- Публичный API ограничивает частоту запросов; для нескольких экземпляров Vercel *настоятельно рекомендуется* подключить Upstash Redis через `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`. Без него действует только локальное ограничение в памяти процесса.
- Форматы: DOCX и текстовые PDF до 10 МБ. Для сканов нужно распознавание OCR (не включено). Текст ограничен для AI-модели размером контекста; длинные документы будут усечены. Импорт неизвестных/неоднозначных ответов требует ручной проверки.
- AI-операции требуют настоящего OpenAI API key и оплачиваются отдельно. Если API недоступен, ручное добавление вопросов возможно через редактор после успешного импорта существующего теста.
- Для результатов сохраняются имя и фамилия ученика: обеспечьте законное основание обработки персональных данных, ограничивайте доступ к Supabase и регулярно делайте резервные копии.

## Пример проверки

DOCX `12345467.docx` содержит тест с 20 вопросами; без ключа ответов AI автоматически выберет определимые варианты, оставив спорные для ручного выбора. PDF `Email.pdf` содержит обучающий материал по электронной почте и облачным сервисам — подходит для режима AI-генерации. Эти примеры не включены в публичный репозиторий во избежание распространения материалов.

## Ограничения проверки

Без реальных Supabase URL, учётной записи преподавателя и OpenAI key невозможно честно подтвердить живой end-to-end сценарий или реальное развёртывание. Перед эксплуатацией выполните также проверку загрузки, публикации и студенческой отправки на своём Supabase-проекте.

## Обновление: автоматическое определение ответов при импорте

При выборе **«Импортировать готовый тест»** можно оставить включённой опцию «Автоматически определить отсутствующие ответы с AI». Загружайте обычный DOCX или текстовый PDF с вопросами и четырьмя вариантами — предварительно проставлять `Ответ: A` не требуется. При желании прикрепите второй DOCX/PDF с учебным материалом: AI будет сверять ответы только с ним; без дополнительного материала использует общие предметные знания и оставляет сомнительные ответы неразрешёнными.

Явные ответы, уже найденные парсером в исходном файле, **никогда не заменяются** предложениями AI. Для остальных вопросов AI работает небольшими последовательными пакетами по пять. Правильные варианты, которые AI смог определить, автоматически принимаются и не требуют отдельной кнопки подтверждения. Для неопределённых или неоднозначных вопросов AI возвращает null — публикация остаётся заблокированной, пока преподаватель не выберет ответ вручную. Ни один ответ не должен считаться безошибочным только потому, что его предложил AI. Второй документ и сами вопросы передаются провайдеру Groq для обработки; не загружайте конфиденциальные материалы без соответствующих разрешений.

Пакетная генерация **новых** вопросов и балансировка позиций A/B/C/D сохранены. Импорт не меняет исходный порядок вариантов. Подготовка AI-ответов может занимать до нескольких минут: `app/api/admin/process/route.ts` задаёт `maxDuration=300`, но фактический предел определяется хостингом.

После обновления: оставьте ваш локальный `.env.local` из старой папки, перенесите его самостоятельно в новую папку проекта, затем `npm install`, `npm run lint`, `npm test`, `npm run build`, `npm run dev`. Новый ZIP специально **не содержит** `.env.local`, `node_modules` и `.next`. SQL-схема не изменялась, повторно выполнять миграцию не требуется.

## Обновление: Groq rate limiting / генерация 20+ вопросов

- Общий для `lib/ai.ts` и `lib/answer-assist.ts` локальный механизм `lib/groq-limits.ts` резервирует приблизительный бюджет токенов в скользящем 60-секундном окне, чтобы последовательные пакеты не отправлялись сразу друг за другом. Оценка токенов консервативная и не заменяет официальные лимиты Groq.
- При HTTP 429 используются `Retry-After` или `try again in ...` из ответа Groq и добавляется небольшой запас времени. При действующих суточных ограничениях автоматическое ожидание не сделает API безлимитным.
- При генерации большого учебного текста пакеты получают ограниченные фрагменты документа (распределённые по его длине), а не полную копию PDF на каждом шаге. Для документов с объёмными таблицами, длинными зависимыми разделами и т. п. обязательно проверяйте покрытие тем и ссылки на источник в редакторе.
- Существующая пакетная генерация по 5 вопросов, рандомизация A/B/C/D и импорт/AI-ответы сохранены. Задержки увеличивают длительность: 20 вопросов могут формироваться несколько минут. `maxDuration=300` в маршруте зависит от лимита выбранного хостинга. Для многочасовых заданий/100 вопросов и многопользовательской эксплуатации потребуется фоновая очередь с БД/Redis, а не один HTTP-запрос. Память процесса не синхронизирует несколько serverless-инстансов.
- Для локальной проверки: `npm install`, `npm run lint`, `npm test`, `npm run build`, `npm run dev`. Попробуйте 5, затем 20 вопросов. При невозможности установить зависимости используйте эти команды на Mac с доступом к npm.
